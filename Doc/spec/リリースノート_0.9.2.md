.NET 10ランタイムを同梱し、本体・管理DLL・ネイティブDLLを単一実行ファイルへまとめています。設定・業務辞書・LICENSE等は外置きです。LinuxではOS側のネイティブ依存ライブラリ、クライアントのWebView2利用機能ではWebView2 Runtimeが別途必要です。

## 今回の主な変更

- **MariaDB／PostgreSQL対応**: サーバ設定 `Database:Provider` でSQLite／MariaDB／PostgreSQLを選べます。SQLiteで記述したSQLを実行時に各DBの方言へ変換します。既存のSQLiteデータは「システム管理 › 保守ツール › DB切替処理」で移行できます。
- **AI照会**: MariaDB／PostgreSQLに対応し、Claude Sonnet 5.5を選べるようにしました。業務辞書を3DB共通の書き方に見直しました。
- **全社分析**: 「分析 › 自由照会」に、年／月／日の推移とドリルダウンができる全社分析を追加しました。
- **印刷無効時の一覧PDF**: PrintStreamを含まない構成（本配布物）では、印刷要求をエラーにせず、印刷データを確認用の一覧PDF（A4横）で出力します。
- **POS連携**: POSアプリ用のサーバI/Fを標準のデータ操作へ統合し、POS精算をレジ別に集計します（POSアプリ本体は本配布物に含みません）。
- **帳票・集計の修正**: 請求台帳の「動きあり」で最初の締期間が出ない不具合、支払台帳の抽出漏れ、最終仕入原価で0円の明細を採用する不具合を修正。買掛金・売掛金管理表の見出しに対象年月を印字。
- **画面**: 未ログイン・ログイン期限切れをメニュー起動前に知らせる、ダークテーマで文字が見えない画面の修正、範囲条件ダイアログの統合、月相表示の改善。ログインが必要なサーバでは天気・気温をログイン後に取得します。
- **その他**: 自動実行の既定スケジュールを夜間0:01〜1:59に依存順で再配置。クライアントSQLのWITH句が構文エラーになる不具合を修正。NuGetパッケージを更新（MailKit 5 等、脆弱性対応を含む）。

上記は対象HEADのソース確認に基づく変更概要で、0.9.2配布成果物での受入完了を示しません。

## サーバの導入

1. 対象OSのZIPを専用フォルダへ展開します。
2. 配布された `appsettings.json` の `ServerVersion` は `0.9.2`、待受はHTTP/2の `http://localhost:5002` です。
3. JWT秘密鍵は空です。配布先で暗号学的乱数から作成した32バイト以上の独自鍵を `WebAuthJwt__SecretKey`、または公開しない `appsettings.Production.json` へ設定してください。
4. `DOTNET_ENVIRONMENT` / `ASPNETCORE_ENVIRONMENT` を `Production` とし、展開先を作業ディレクトリにしてWindowsは `CvServer.exe`、Linuxは `chmod +x CvServer` の後に `./CvServer` を実行します。

SQLite DBは既定で作業ディレクトリの `server.db` です。新規DBでは管理者が作成され、初期ID・パスワードはどちらもDB作成日の `yyyyMMdd` です（有効期限1か月）。ログイン後に運用用の利用者設定へ変更してください。既存DBを使う場合は起動前にバックアップしてください。

MariaDB（10.11 LTS以上、`utf8mb4_bin`）／PostgreSQL（16以上、`LC_COLLATE=C`）で運用する場合は、`Database:Provider` を `MariaDb`／`Postgres` にし、`ConnectionStrings:MariaDb`／`ConnectionStrings:Postgres` に接続文字列を設定してください（配布の `appsettings.json` には記載がありません）。既存のSQLiteデータを移す場合は、SQLiteで起動した状態でDB切替処理を実行してから `Database:Provider` を変えて再起動します。移動先の表は削除・再作成されます。

別端末から接続する場合は、サーバ側のHTTPS・HTTP/2待受、証明書、ネットワーク設定を構成し、クライアントもそのURLへ合わせてください。Windowsサービス・systemdへの登録は自動では行いません。

## クライアントの導入

1. Portable ZIPを、書き込み可能な専用フォルダへ全体を展開します。
2. 展開先直下の `CreativeVision10.exe` を起動します。`current/` 以下の構成を保持してください。
3. 同梱 `current/appsettings.json` の版数は `0.9.2`、接続先は `http://localhost:5002` です。
4. 通常起動では `%LOCALAPPDATA%/CreativeVision10/clientsettings.json` の設定が優先されます。初回の設定未作成時も既存実装の初期値 `https://localhost:5012` が使われるため、ログイン前に環境設定（F10）で接続先を `http://localhost:5002`（別端末では実際のサーバURL）へ設定・保存し、再起動してください。

起動前に設定ファイルを作る場合の最小内容:

```json
{
  "ConnectionStrings": {
    "Url": "http://localhost:5002"
  }
}
```

保存済み設定がある場合は接続先だけを変更し、他の設定を上書きしないでください。

## 0.9.1からの更新

- 新しい版のZIPを別フォルダへ展開し、接続先・JWT鍵などの設定を引き継いで切り替えてください。

## 更新・制限

- 自動更新用のフィードは設定していません。
- `PrintEnable=false` で発行しており、帳票形式の印刷はできません（確認用の一覧PDFになります）。`printstream.jar`・IKVM依存は実行ファイル内部にも含めていません。一覧PDF用に IPAゴシックを同梱し、そのライセンス文書を添付しています。
- ID・パスワード・APIキー・運用DB・証明書・秘密鍵は同梱していません。
- ARM64、Alpine/muslは対象外です。
