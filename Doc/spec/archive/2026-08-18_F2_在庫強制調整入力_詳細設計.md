## 1. 前提の確認（VMの旧コメントは陳腐化）

`StockForceInputViewModel` の旧コメントは「調整を保存する場所が無い（案A/案B）」としていたが、
その後 **案A が実装済み**である。

- `Tran61Chosei`（在庫調整伝票）が新設され、`ITranSoko` を実装している。
- `TranCalcBase.GetCalcSoko(nameof(Tran61Chosei))` は `(1,0,0,0)`（実在庫を動かす）を返し、
  別に `GetCalcAdjust` が `AdjustQty` へ積む（受払表で入出庫と区別）。在庫恒等式は `Su = InQty + OutQty + AdjustQty`。
- サーバの汎用CRUD副作用起動役 `WriteEffectRunner.CalcStock` は `is ITranSoko` で判定するため、
  **`Tran61Chosei` を通常のInsert/Update/Deleteで保存すれば在庫が自動で更新される**（棚卸確定処理と同じ経路）。
- 伝票にしているので全件Rebuildでも消えない（「通常更新値 = Rebuild値」を守る）。

したがって **在庫強制調整入力はクライアントに閉じる**（サーバ・スキーマ・新規Msgは不要）。

## 2. スコープ

本作業は **在庫強制調整入力（登録）** を実装する。

- **入力（登録）**: 倉庫のSKUを一覧に並べ、行ごとに**調整数（符号付き）**を入力して `Tran61Chosei` を1伝票登録する。
  区分は強制調整(`EnumChosei.Kyosei=20`)。登録で在庫へ即時反映（プラスで増、マイナスで減）。

**follow-up（本作業では実装しない・別課題）**:
- **取消（既存調整伝票の削除）** と **在庫強制調整実績照会（帳票/一覧）**: `Tran61Chosei` の一覧・削除UI／qfmが要る。
  一覧方式の登録画面(`BaseStockSheetInputViewModel`)は登録専用のため、別画面として設計する。当面の是正は
  「反対符号の調整をもう1件登録する」で代替できる（伝票が残り監査も追える）。
- **調整理由(`Tran61Chosei.Id_Riyu`)**: 参照先の `MasterMeisho` 調整理由区分がまだ定義されていない
  （列コメントのみ）。区分コードを勝手に決めると後の決定と衝突するため、当面は**メモ**で理由を残し `Id_Riyu=0` とする。
  理由マスタ区分が決まった時点で選択UIを足す。

## 3. 実装方針

一覧方式入力の共通基底 `BaseStockSheetInputViewModel<TDen>`（棚卸入力(一覧)／移動入力(棚)で実績あり）を再利用する。
この基底は「倉庫・日付・担当者・メモ＋対象SKU一覧＋数量入力＋1伝票登録(InsertParam)」を提供し、
在庫反映はサーバの汎用CRUDに委ねる。

- **新規実装**: `ViewModels/08Zaiko/StockForceInputViewModel.cs` を
  `BaseStockSheetInputViewModel<Tran61Chosei>` の派生として作る。空クラスから置き換える。
  - `QueryTitle` = "在庫強制調整入力"、`InputSuHeader` = "調整数"。
  - `LoadRowsAsync`: 棚卸入力(一覧)と同じく、対象倉庫の在庫SKU（+品番範囲指定時は在庫0のSKUも）を並べる
    （基底の `LoadStockAsync/LoadSkuAsync/LoadShohinMapAsync/LoadSkuMapAsync/CreateRow` を再利用）。
  - `BuildDenpyo`: `new Tran61Chosei { EnKubun = EnumChosei.Kyosei }`（DenDay/Id_Soko/Id_Shain/Memo/Jmeisai/合計は基底が詰める）。
  - 理論在庫の初期値流し込み(`IsPrefillTheoretical`)は**しない**（調整数は0から入力）。
- **View**: `Views/08Zaiko/StockForceInputView.xaml` を棚卸入力(一覧)Viewを土台に作る。
  棚番を外し、「棚卸日→調整日」「実棚数→調整数」「理論在庫→現在庫」に読み替え、
  「調整数を入力した行だけ登録」「登録で在庫へ即時反映（マイナスで減算）」の注意書きにする。
- サーバ・`Tran61Chosei` スキーマ・`WriteEffectRunner` は変更しない。
