# I7 follow-up 滞留・欠品一覧の出力（CSV） 詳細設計（2026-08-18）

対象HEAD: `4678543`（受注側納品予定照会）
対象: 滞留・欠品例外画面（`ShippingConfirmList`）への CSV 出力追加
根拠: 未適用課題台帳 I7 の follow-up「純・帳票印刷版の出荷指示一覧」。

## 1. 方針の判断（PDF帳票ではなく CSV 出力）

「出荷指示一覧の印刷版」を検討した結果、**PDF帳票（qfm）ではなく CSV 出力**で実装する。

- qfm は座標指定のXMLレイアウト（`printform/*.qfm`、SHIFT_JIS）。新規レポートの qfm を新設するには
  列位置・幅・フォント・改ページ等を手で組む必要があり、**生成PDFを目視確認できない環境では品質を担保できない**
  （小さなズレで崩れたレポートを出してしまうリスク）。
- 滞留・欠品の一覧は既に interactive 画面（I7 本体）で検出・操作でき、"一覧を外部へ出す" 目的は
  **CSV 出力で確実に満たせる**（Excel 等で印刷可能）。CSV はテキストで生成結果を論理的に検証できる。

したがって本 follow-up は CSV 出力を提供し、**専用の PDF帳票（qfm）は別途 report designer が必要なため見送り**とする（台帳へ明記）。

## 2. 実装（クライアントに閉じる）

- `ShippingConfirmListViewModel` に `ExportCsv` コマンドを追加。表示中の `Rows`（滞留 or 欠品実績）を
  現在の表示列（確定日・納品予定日・経過日数・予定日超過・倉庫・出荷先・種別・商品・色サイズ・指示数・実数量・欠品）で
  CSV（UTF-8 BOM）へ書き出す。`Microsoft.Win32.SaveFileDialog` で保存先を選ばせ、既定名は `滞留欠品例外_yyyymmdd.csv`
  （日付は端末日付）。ヘッダのカンマ・改行はエスケープ／畳み込みする（配分照会のCSVと同方式）。
- View に「CSV出力」ボタンを追加。

サーバ・スキーマ変更なし。
