# プロモーション動画レンダラ（動画生成AI不使用）

Creative Vision 10 のプロモーション動画を、Python のコードだけで1コマずつ描画して mp4 にするツール。
映像は numpy / Pillow による2D合成・3D射影・粒子描画、音楽と効果音は numpy / scipy による合成で、外部素材は repo 内の実データ（コミット履歴・ロゴ・UAT のスクリーンショット・帳票 PDF レンダリング）だけを使う。

2026-10-22 に v1〜v3 の3本（下表）を作成した。新しい動画も、ここのエンジンと既存の台本ファイルをひな型にして作る。

| ファイル | 内容 | 尺 |
|---|---|---|
| `v1.py` GENESIS | 実コミット1,801件の二重螺旋 → 3層アーキテクチャ → 業務領域の地球儀 → 数字 → 24,000粒子でロゴ形成 | 52秒 |
| `v2.py` 十の利点 | 120BPM に同期したキネティック・タイポグラフィ（README の十のメリット）＋実画面モンタージュ | 40秒 |
| `v3.py` REAL SCREENS | 実画面の壁、業務フロー6画面の3D巡回（床面反射）、帳票の螺旋、4種DB、実画面サムネイルのフォトモザイクでロゴ | 48秒 |

## 構成

| ファイル | 役割 |
|---|---|
| `core.py` | エンジン。補間・イージング、文字画像、合成（blit）、グロー/ブルーム/ビネット/色収差/粒状感、粒子スプラット、3Dカメラと射影、板の射影変換、音声合成（キック・パッド・ライザー等）、ミックスとリバーブ |
| `run.py` | 並列レンダリングと ffmpeg エンコード、静止画書き出し |
| `sheet.py` | 直近の静止画をコンタクトシートにまとめる（目視確認用） |
| `prepare_assets.py` | 素材の準備（実画面・帳票画像の収集、コミット時刻、透過ロゴ） |
| `v1.py`〜`v3.py` | 台本（各動画）。`DURATION`、`render(t) -> (H,W,3) float`、`audio() -> (N,2) float` を持つ |

素材と出力は容量が大きいため、リポジトリ外扱いの `Doc/promo/`（`.gitignore` 対象）へ置く。環境変数 `PROMO_DIR` で変更できる。

```text
Doc/promo/assets/  screens/ forms/ commits.txt logo_alpha.png
Doc/promo/out/     v1.mp4 … / stills/<名前>_<時刻>/（確認用静止画）
```

## 準備

- Python 3.12 以降（3.14 で確認）。ffmpeg は `imageio-ffmpeg` 同梱のものを使うため別途インストール不要。
- フォント: Windows 標準の Noto Sans JP（可変、太さ指定）、游明朝、Segoe UI、Cascadia Mono。
- 実画面・帳票は `Doc/test/uat20*` 等（`.gitignore` 対象）にあるローカルの UAT 成果物から集める。別の環境では UatVm 等で画面を保存してから実行する。

```text
pip install -r requirements.txt
python prepare_assets.py
```

## 使い方

コマンドはこのフォルダで実行する。

```text
python run.py v1 --stills 2,10,25,48   指定秒の静止画を書き出し（数秒で終わる）
python sheet.py v1 8                   直近の静止画を8枚ずつシート化
python run.py v1 --range 10 14         区間だけ軽い設定で mp4 化（動きの確認）
python run.py v1 --audio               音声だけ書き出し
python run.py v1                       本番（CRF15、音声 AAC 256k を多重化）→ Doc/promo/out/v1.mp4
```

24論理コアで本番レンダリングは v1 約5.5分、v2 約1分、v3 約3分。同時に2本回す場合は `--procs` で並列数を分ける。

本番出力は粒状感のため 190〜375MB になる。配布用は次で 70〜90MB 程度に縮める。

```text
ffmpeg -i v1.mp4 -c:v libx264 -preset slow -crf 21 -maxrate 14M -bufsize 28M -pix_fmt yuv420p -c:a copy -movflags +faststart v1_share.mp4
```

ffmpeg の場所は `python -c "import imageio_ffmpeg as f;print(f.get_ffmpeg_exe())"` で確認できる。

## 新しい動画の作り方

1. 既存の `v*.py` を複製して `v4.py` 等にする。方向性が近いものをひな型にする（粒子＝v1、文字中心＝v2、画面・帳票の3D＝v3）。
2. 冒頭コメントに場面の秒割りを書き、`render(t)` を場面ごとの関数に分ける。場面の切替は v3 の `SCENES` のように区間を重ねてクロスフェードする。
3. 音楽は BPM を決め、映像のカット・スラムを拍頭に置く（v2 は `BEAT=0.5` 秒で全カットを拍に合わせている）。効果音は映像のイベント時刻と同じ定数から配置する。
4. `--stills` で各場面の要所を出し、`sheet.py` で目視する。確認後に本番レンダリングする。

## 目視確認で直した点（再発防止）

- 暗い背景の粒子は想定より暗く見える。重み（v1 の `PBOOST`）とグローで持ち上げ、`tonemap` で白飛びを抑える。
- 白い UI 画面はブルームで白飛びする。画面を扱う動画はブルームの閾値を 0.9 以上にする。
- 見出しと3D物体が重なる。`Camera.cx`（主点）をずらして被写体を片側に寄せ、文字側に暗幕を敷く。
- 長い日本語見出しは1行に収まらない。2行に分け、右端からはみ出す注記は幅を測って左へ寄せる。
- ロゴ画像の背景は純白ではない（約 #F7F6FC）。明るい背景に置くと枠が見えるため `logo_alpha.png` を使う。
- フォントにない記号（例: ▶）は豆腐になる。静止画で確認し、Segoe UI にある記号（→ ↓ 等）を使う。
- 寄りで中身が読めないモザイクは「画面でできている」ことが伝わらない。高解像度で作り、寄りから引くカメラで見せる。
- 静止画フォルダは実行ごとに時刻付きで分かれる。不要になったら `Doc/promo/out/stills` を手で消す。
