# プロモーションソング生成ツール

CV10 のプロモーションソング「Creative Vision 10！ ～明日へ飛べ～」を、楽譜データから伴奏・歌・ミックス・マスタリングまで作るツール。
伴奏のドラム・ギター・ベースは実録サンプル（CC0）、和楽器は物理モデル等の合成、歌は VOICEVOX Engine（無料・ローカル実行）で合成する。

企画・歌詞・バージョン・クレジット表記は `Doc/promo/song/README.md` にある。

## 構成

| ファイル | 役割 |
|---|---|
| `song.py` | 楽譜データ（`SECTIONS`、旋律テンプレート、各番の歌詞）、検算、`譜割り.md`・MIDI の書き出し |
| `band.py` | 和ロック編成の伴奏（ドラム・ギター2本・リードギター・ベース・箏・三味線・尺八・和太鼓・パッド）、アンプ・キャビネット、ミックス（パート間ラウドネスの自動調整）、マスタリング（マッチ EQ・リミッター・ラウドネス）、AAC 化 |
| `sampler.py` | 実録サンプルの読み込みと発音（ファイル名の規則から音域・強さ・ラウンドロビンを選ぶ。FLAC は ffmpeg で展開してキャッシュ） |
| `sing.py` | VOICEVOX で歌わせ、音程補正・ビブラート・ダブル・ハモリ・掛け声・ボーカル処理をして完成版を書き出す。声のオーディション |

音源合成の基本関数は `../promo-video/core.py` を使う。出力先は `Doc/promo/song/`（`.gitignore` 対象。環境変数 `PROMO_SONG_DIR` で変更可）。

## 準備

- Python 3.12 以降（3.14 で確認）。`../promo-video/requirements.txt`（numpy / pillow / scipy / imageio-ffmpeg）。
- VOICEVOX Engine を https://github.com/VOICEVOX/voicevox_engine/releases から取得し、`Doc/promo/song/voicevox_engine/`（`run.exe` がある階層）へ展開する。別の場所なら環境変数 `VOICEVOX_ENGINE` に `run.exe` のパスを指定する。
- 伴奏のサンプル集（CC0）を `Doc/promo/song/samples/` へ展開する（環境変数 `SAMPLES_DIR` で変更可）。各リポジトリの zip（Code → Download ZIP）を展開したフォルダ名のまま置く。
  - https://github.com/sfzinstruments/karoryfer.big-rusty-drums （約590MB）
  - https://github.com/sfzinstruments/karoryfer.emilyguitar （約100MB）
  - https://github.com/sfzinstruments/karoryfer.growlybass （約160MB）
  - 2026-10-22 は 0.25.2 の NVIDIA 版（`7z.001`・`7z.002` を連結して `py7zr` で展開）を使った。RTX 50 系は同梱 CUDA が非対応で GPU 合成が失敗するため、`sing.py` は CPU で起動する。CPU 版（`.vvpp` は zip として展開可）でもよい。

## 使い方

コマンドはこのフォルダで実行する。エンジンが起動していなければ `sing.py` が自動で起動・終了する。

```text
python song.py                    譜割りの検算と 譜割り.md・creativevision10.mid（1秒）
python band.py [--stems]          伴奏だけ creativevision10_inst.m4a。--stems でパート別 WAV と帯域・ラウドネス表 stems/levels.md（約1分）
python sing.py --list             声（スタイル）の一覧
python sing.py --audition         サビ1を全候補（AUDITION）で歌わせ、調波性・倍音比・音程・明るさ・急変で順位付け → audition/（約5分）
python sing.py                    四国めたん版 creativevision10_full_metan.m4a・_vocal_metan.m4a と伴奏 _inst.m4a（約2分）
```

バージョン違い（`Doc/promo/song/README.md` 2章）は次で作る。`--tag` を付けると `creativevision10_full<tag>.m4a` と `_vocal<tag>.m4a` を書き出す。

```text
python sing.py --singer 3054 --verse 3054 --gang 3054 3009 3046 3016 --tag _nana
python sing.py --singer 3043 --verse 3043 --gang 3043 3009 3046 3016 --tag _miko
python sing.py --singer 3011 --verse 3011 --octave -1 --gang 3009 3046 3016 --tag _takehiro
python sing.py --singer 107 --verse 107 --key -7 --gang 3009 3046 3016 --tag _zunko
python sing.py --singer 3003 --verse 3001 --gang 3003 3009 3046 3016 --tag _zundamon
python sing.py --singer 3009 --verse 3009 --harmony 3055 --gang 3009 3055 3046 3016 --tag _ritsu
python sing.py --singer 3055 --verse 3055 --gang 3055 3009 3046 3016 --tag _al
python sing.py --singer 3023 --verse 3023 --gang 3023 3009 3046 3016 --tag _whitecul
python sing.py --singer 3010 --verse 3010 --gang 3010 3009 3046 3016 --tag _hau
python sing.py --singer 3061 --verse 3061 --gang 3061 3009 3046 3016 --tag _usagi
```

| 引数 | 意味 |
|---|---|
| `--singer` / `--verse` | メインの声（Aメロだけ別スタイルにできる。四国めたんはノーマル 3002 / あまあま 3000） |
| `--harmony` | サビのハモリ（既定 3009 波音リツ） |
| `--gang` | 掛け声「いこう！」を重ねる声 |
| `--octave` | メインとダブルだけを移すオクターブ（男声は -1。ハモリは原音域のまま上に乗る） |
| `--key` | 伴奏ごと曲全体を移調（半音） |

## 楽譜の書き方

- メロディは D メジャー表記で書き、`KEY = -2` で C メジャーにして鳴らす。セクションの `shift=1` はさらに半音上げる（ラストサビの転調）。
- 音符は「音名オクターブ.8分音符数」（例 `F#5.2` は4分音符）、休符は `r.1`。
- 歌詞は（表示, 読み）の組。読みは**歌う発音**で書く（助詞の「へ」は「え」、「は」は「わ」）。1音符に1モーラを当て、`っ`・`ん`・`ー` も1モーラ、拗音は前の文字と合わせて1モーラ。
- 2番・ラストサビは同じ旋律テンプレート（`A_L*`、`B_L*`、`S_L*`）に別の歌詞を当てる。歌詞を変えるときはモーラ数を揃える。
- 実行時に、フレーズごとの「モーラ数＝音符数」と、セクションごとの「8分音符の合計＝小節数×8」を検算する。
- 伴奏の演奏法はセクション名で `band.py` の `PLAN` に、セクションごとの音量は `SECTION_LEVEL`（伴奏）と `sing.py` の `SECTION_GAIN`（歌）にある。

## 仕組み

### 伴奏（band.py）

- ドラムは近接マイクとオーバーヘッドを混ぜ、強さとラウンドロビンを毎打変え、タイミングを数 ms 揺らす。Aメロはゴーストノート、サビはハーフオープンのハイハット、各セクション頭にクラッシュ、終わりにタムのフィル。
- ギターは DI 素材を弦ごとに数 ms ずらして鳴らし（ストローク）、ノイズゲート → オーバードライブ → 歪み → 4x12 キャビネット特性の FIR を通す。左はハイゲインのパワーコード（Aメロはブリッジミュート）、右はクランチのアルペジオとフルコード。
- ベースは DI 素材（Aメロはスタッカート）。素材の基音が弱いため、基音の正弦波を足す。
- 和太鼓はミュートなしのバスドラムを低く移調、縁打ちはリムを低く、締太鼓はリムを高く移調する。打ち方はセクションごとに `taiko_bar`（Aメロは4小節ごとに小さく、Bメロで打数を増やし、サビは毎小節頭の低い一打と「ドドン」）。箏・三味線は Karplus-Strong、三味線はさわりと撥の打撃音、尺八は息・ムラ息・メリ・揺りで合成する。
- ミックス: サビで各パートのラウドネスを測り、`PART_LU`（ドラム基準）の比に合わせる。キックでベース・パッドを下げるサイドチェイン、ドラムバスのコンプとルーム、和楽器のホール、リードギターのディレイ。
- マスタリング: 市販ポップスの平均的な帯域バランス（`TARGET`）との差を ±5dB まで補正する直線位相 EQ、軽いグルーコンプ、4倍オーバーサンプルのピークで判定する先読みリミッター、BS.1770 ラウドネスで -12 LUFS へ合わせる。AAC 化後のサンプル間ピークを測り、-1 dBTP を超えたら下げて作り直す。冒頭に 0.2 秒の無音を置き（動画と合わせるときはこのぶんずらす）、最後の一撃の余韻が -30dBFS まで下がったところから 0.4 秒でフェードアウトして切る。

### 歌（sing.py）

1. 歌のあるセクションごとに1テイクとし、音符を絶対フレーム（93.75fps）で丸める。丸めの重なりや数フレームの隙間は前後へ吸収する。
2. 歌唱指導モデル（style 6000）で音高・音素長を作り、f0 を加工する（音程の偏差を縮め、高音でずれる音はほぼ正確に、伸ばす音へ遅れて掛かるビブラート）。音量は加工後の f0 で作り直し、選んだ声で合成する。
3. 歌唱モデルのない声（東北ずん子）は話し声モデルで歌わせる。各モーラの音高を音符に、子音を拍の前・母音を拍頭に置いて長さを合わせ、合成音の音程を測って音高へ戻す補正を3回繰り返す。仕上げに母音区間を作り直す。各フレームで話し声の倍音振幅から声色（包絡）を測り、歌唱指導モデルの f0 カーブ（他の声と同じ歌い方）の倍音として合成し直す（かすれ・息の雑音を残さない）。子音は元の音を使い、フレーズ間の休符は無音にし、息継ぎは入れない。小さすぎる母音は持ち上げる。歌い方として「よう」の「う」は「お」、伸ばす「ン」は前の母音を7割伸ばしてから「ン」にする。高音が出ないため伴奏ごと移調する（`--key -7`）。
4. サビ・アウトロは揺らぎを変えたダブル2本、ダイアトニック3度下のハモリ2本、掛け声を重ねる。
5. ボーカル処理（HPF・こもり除去・明瞭度・コンプ・ディエッサー・高域補完）、プレートリバーブ、付点8分ディレイ。歌がある間は伴奏の 1.2〜4.5kHz を下げて歌の通り道を空ける。
6. セクションごとに歌と伴奏の K 特性ラウドネス差を測り、`VOCAL_REL_LU`（Aメロ +3 / Bメロ +2 / サビ +1.5 / アウトロ +2 LU）に合わせる。

## 再発防止メモ

- 長さ1フレームの休符があると `sing_frame_audio_query` が内部エラーで落ちる。
- 音符頭を丸めたまま前の音の終わりと重ねると、エンジンは前の音の終わりから置くため、ずれが累積する（サビ後半で約75ms遅れた）。
- `sing_frame_f0` / `sing_frame_volume` は歌唱指導モデル（6000）でしか動かない。声の指定は `frame_synthesis` だけで行う。
- 歌詞に `ー` は使えない（直前の母音へ置換）。`ッ` は使える。
- 帯域の偏りはマスター EQ で直しきれない（目標との差が ±5dB を超える）。`band.py --stems` の `levels.md` でどのパートが原因かを見て、音源側で直す（キック・太鼓の超低域、ベースの音域と歪みの高域、ギターの中域を直した）。
- AAC は打撃音で 0.2〜0.8dB 程度ピークが上がる。曲頭の1拍目に一撃があると先頭フレームで大きく超えるため、冒頭に無音を置く。
- 話し声モデルは C5 付近より上で崩れ、D3 付近より下でかすれる。指定した音高からも数十セントずれるため、測って戻す補正が要る。音程推定は探索範囲を目標の前後に絞らないと1オクターブ違いを拾い、補正が逆に大きく外れる。
- 実録ベース（Growlybass）は表記より1オクターブ低い実音で、基音がほとんど録れていない。
- 伴奏の編成を変えるとセクションごとの音量が変わり、歌と伴奏の比が崩れる（Aメロ +8 LU、Bメロ -0.6 LU になった）。比は全体でなくセクションごとに合わせる。
- オーディションの順位は調波性・明るさ・スペクトル急変から機械的に出したもので、最終判断は聴いて行う。
