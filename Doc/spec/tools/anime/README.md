# プロモーションアニメ レンダラ（動画生成AI不使用・GPU シェーダ描画）

Creative Vision 10 のプロモーションアニメを、主人公の一枚絵（`Doc/promo/assets4anime/github-logo-gemini-*.png`）と repo 内の実データ（フルバージョンは背景の静止画2枚とミニキャラのスプライトも）から、Python + GLSL のコードで1コマずつ描いて mp4 にするツール。
動画生成AI・既成の映像素材は使わない。入力の静止画（主人公の一枚絵、フルバージョンの背景2枚、v2 は主人公の背景なしの表情差分・立ち絵・シーン別の連続コマ）のほかに画像を生成せず、動き・光・天候・演出はすべてコードで付ける。

## v3 柔らかアニメ調（補助、2026-10-26）

> **補助メモ**: v3（`op3.py` / `opfull3.py`）は、明るく柔らかいアニメ調に振った補助の版。プロモーションの主力は v2（`op2.py` / `opfull2.py`）とし、v3 は場面や好みに応じて使い分ける控えとして残す。歌・歌詞・実データ・主人公の素材は v2 と共通。

`op3.py` は op2 と同じ主題歌 v2・歌詞・実データ・主人公の素材で、画づくりを明るいポップな OP 調に作り替えた台本（68秒、11の歌い手の版）。`Doc/promo/assets4anime/sampleimage/shootingstar.mp4` からは演出の型だけを参考にし（白地の紙吹雪とロゴ、見上げた夜の街、渦、文字が1つずつ弾む見出し、拍で色が変わる水玉と同心円の背景、大きな薄い英字、傾いたカード、舞台のフレア、夕焼けの筋雲、ハートの噴き上がり、ネオンのロゴ）、参考動画の映像・音声は使わない。

- 背景・図形・文字は `pop.py` の GLSL で描く: 水玉と同心円の背景、渦（対数らせんの3色の帯）、平塗りのビルを消失点へすぼめた見上げの街、紙吹雪・星・ハート・タイル（SDF）、押し出した影の厚い文字と1文字ずつの弾み、ネオン管の筆記体、円形のワイプ、夕焼けの筋雲。
- 主人公は op2 と同じ（6表情のリグ・立ち絵・シーン別の連続コマ）。顔の寄りと立ち絵は白い縁取りでシール風にする。5人の色違い（`dance-parts-v1/cast-lineup.png`）を「目指すはひとつ」で並べる。
- 実データは op2 と同じく実行時に数える（AI と共同のコミット数・実画面数と画面名・実テスト名と数・日ごとのコミットのタイル）。エンディングのドラムソロは実画面と、立ち絵・表情から DoG で起こした線画（`work/op3/`）のカード。
- 歌詞のカラオケ、クレジット、プロデューサー・リポジトリ・QR は op2 の関数をそのまま使う。

フルバージョン（`opfull3.py`）は 0〜57.8秒が `op3.py` と同じで、2番・サビ2・ブリッジ・ラストサビ・アウトロを同じ画づくりで新しく作る（秒割りは冒頭コメント）。

Codex による第一弾（Pillow で静止画を並べる方式）は不採用。その出力は `out/op3_metan_nogood.mp4` に改名して残す。

## GPU シェーダによる高速描画

合成・変形・光の処理はすべて ModernGL（OpenGL 4.3）の GLSL シェーダで行う。内部は2倍の解像度（3840x2160）で描いて縮小し、1コマに3回描くモーションブラーを入れても、RTX 5080 で68秒の作品を約50秒（実時間より速い）で書き出せる。
CPU の numpy で描く `../promo-video`（v1 で約5.5分）と比べて桁違いに速いため、静止画で確認→全編書き出し→見直しを何度も回せる。

## 仕組みの要点

- **一枚絵を動かす**: 4つの表情画像はキャラの位置がそろっているため、顔の領域だけ・全体を、重みで混ぜて表情を変える。変形は描画先の画素から元画像の座標を逆にたどる（頭は首を軸に回転、帽子・リボン・イヤリングは遅れて追従、髪は下ほど大きく波打つ）。背景は穴埋めした板の上に切り抜きを重ねるので、動いても背景が引きずられない。
- **まばたき**: 目の領域（まつげ〜下まぶた）を画像から測り、列ごとの上端・下端を4次式で近似した表を作る。閉じるときは目を消した肌で上から覆い、元のまつげの帯を下ろしながら細くする。閉じきると弧を描いた閉じ目になる。
- **口パク**: ハッピー顔の開いた口を切り出し、開き（縦）と幅（横）を母音ごとに拡縮して、口を消した顔に重ねる。歌は譜割りの母音と歌だけの音源の音量、台詞は VOICEVOX のモーラ長と台詞の音量から決める。
- **主人公の紙細工**（book）: リグの絵を毎コマ 1600px のオフスクリーンに描き、型抜きの白い縁ごと3Dの板に貼る。
- **オルゴール**（book）: 主題歌の Bメロ・サビの旋律とコードを 112BPM に直し、FM のベル音で合成してリバーブをかける。
- **背景なしの主人公**（v2）: onlyperson は旧リグの一枚絵の描き直しで顔の位置がほぼ一致するため、特徴点（SIFT）と顔の ECC で旧リグの座標へ合わせて置く。帽子の上端が一枚絵の外へはみ出すので、キャンバスは原点 (-64,-320)・一辺 2400 の正方形にし、台本の位置指定（`op.char_H`）はそのまま使う。まばたき・口は onlyperson で測り直す。ハッピー顔のまばたきは目を閉じた笑顔の目の領域へ差し替える。ハイテンション顔は描き直しで位置がずれているため、顔以外で合わせてから使う。
- **連続コマ**（v2）: 生成したコマはキーごとに数十 px ずれるため、帽子・頭など動かない部分でコマ0に合わせる。補間したコマは1枚ずつの推定のばらつきで揺れないよう、補正量を時間方向にならす。コマは描き分けた絵なので変形はせず、時刻で送る。素材の秒数をショットの長さに合わせて引き延ばすと遅く・カクついて見えるため、シーンごとの自然な速さ（`op2.py` の `FB_PLAY`）で送り、尺が余ると折り返す（歩く・手を伸ばすは折り返さない）。再描画したコマ（v3）はコマ間で細部が揺れるので、風・飛ぶ・飛び込むは素材の 0.8〜0.85 倍で送る。
- **歌詞 v2 の組み直し**: v2 は旋律・秒割りが v1 と同じで、1番と2番の歌詞が入れ替わっている。同じ歌詞の既存ショットは時刻をずらして使い（口パクだけ v2 の歌の時刻で読む）、入れ替わった行だけ新しく作る。

## 目視確認で直した点（再発防止）

- ACES 等のトーンマップはイラストの色を白っぽく変える。0.8 までは素通しにし、それより上だけを丸める。ブルームの閾値は 1.1（イラストの白は光らせない）。
- 光条（god rays）は明部全体を拾うと画面が白飛びする。光源からの距離で重みを絞る。
- 朝焼けの淡い空の上の白文字は読めない。文字の背後に暗い光を敷くか、濃い空にする。
- 3D カメラの右方向は `cross(up, forward)`。逆にすると板に貼った文字が鏡文字になる。
- 表裏で絵を変える紙は、三角形の巻き方向ではなく、法線が視点を向くかで表裏を決める（右ページだけ真っ暗になった）。
- FBO のテクスチャは下の行から並ぶ。オフスクリーンに描いた絵を板に貼るときは上下を反転して描く。
- GLSL では `half` は予約語。
- フォントにない記号は豆腐になる（Segoe UI Bold に ✓ ✦ はない）。記号は Segoe UI Symbol（`sym`）で描き、静止画で確認する。
- VOICEVOX の語りは読点ごとの間が長い。`pauseLengthScale`（`voice.say(..., pause=)`）と話速で尺に合わせる。
- 元絵に描かれた効果音の文字（TAP! 等）は、その画像を全体に使うと出る。ハイテンション顔は顔の領域だけに使う。
- 開いた口を縦に縮めるときは、左右の口角を結ぶ線へ向けて縮める。口の上端の水平線へ縮めると、低い位置にある左の口角が持ち上がり口元が歪む。元の口の右上がりの傾きも浅くする（`rig.py` の `MC0`・`MK0`）。
- 部屋の背景の板は 2048px の正方形なので、倍率 0.94 未満では画面の横が余る。
- 生成画像（`Gemini_Generated_Image_*.png`）は右下に透かし（✦）がある。消さずに切り出しで画面の外に置く（`prep_full.py` の `FUJI_CROP`・`SEASONS_CROP`）。
- `prog(t, a, b)` は a > b を受け付けない（段差になる）。下がっていく範囲は `1 - prog(t, b, a)` と書く（スタッフロールの下半分が消えた）。
- 湖面のゆらぎは波長を数画素より長くする。細かい正弦波で映り込みをずらすと折り返してギザギザの模様になる。
- 3D の板がカメラの後ろへ回ると `quad_h` が None を返して丸ごと消える。長い板は分けて描く（日ごとのコミットの表）。
- 明るい空の上の加算の光は白く飛んで見えない。暗い空にするか、色を残す大きさ・強さにする（声の光の輪）。顔の前を通さない。
- 一枚絵の切り抜き（GrabCut）は、髪の房の間から見える背景を主人公として塗りつぶし、外側の髪の帯を背景にすることがある。`prep.py` の `fix_hair` で、外側の黒い縁取りまで髪を足し、房の間の無彩色の塊を抜く。
- ハッピー顔の開いた目を通常顔の目の表で閉じると、まつげの帯の位置が合わず元の目の輪郭が薄く残る。目を閉じた笑顔の素材があれば、目の領域をそれへ差し替える方が自然。
- 立ち姿の絵を回転して飛ばしても、立っているようにしか見えない。飛ぶ・歩く・手を伸ばすなど動作ごとの絵（連続コマ）を使う。
- 生成した連続コマを並べただけでは、キーごとの位置ずれで頭が跳ねる。動かない部分で位置を合わせる（`prep_person.build_scenes`）。
- GLSL の `smoothstep(a, b, x)` は a == b のとき結果が未定義。渦の穴の半径を 0 にすると画面全体が穴（夜空）になった。0 のときは計算しない（`pop.py` の `SWIRL_FS`）。
- 明るい地の上のネオンは、ブルームで白く飛んで読めない。暗い看板の板を敷き、光の強さを抑える（v3 のロゴ）。
- カットの多い作品で毎回カットの頭に強い閃光を入れると、画面全体が白っぽく見える。v3 では op の半分程度の強さ・長さにした。
