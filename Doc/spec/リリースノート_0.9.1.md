# CreativeVision10 0.9.1

状態: **公開用原稿（配布成果物作成済み、GitHub公開は人間対応）**。確認日: 2026-10-27／調査対象HEAD: `763bd3eae66a33ef29323a2382d28a5afd20d556`。

gRPCサーバ（Windows / Linux x64）とWPFクライアント（Windows x64）を配布します。

.NET 10ランタイムを同梱し、本体・管理DLL・ネイティブDLLを単一実行ファイルへまとめています。設定・業務辞書・LICENSE等は外置きです。LinuxではOS側のネイティブ依存ライブラリ、クライアントのWebView2利用機能ではWebView2 Runtimeが別途必要です。

## 今回の主な変更

- 顧客カルテからポイント履歴・残高を照会できる画面を追加。
- 自然言語からSQLを生成し、結果をCSV／JSONへ保存するAI照会を追加。共有・個人保存に照会条件を保持。AI接続設定は配布先で別途用意。
- メニュー利用履歴、権限プロファイルによるメニューの表示・起動制御、PC・ログインID別のお気に入りを追加。メニュー制御はクライアント側の業務補助で、サーバの認可境界ではありません。
- 旧DB変換後の商品色サイズ派生再作成、関連Noのlong統一、ポイント履歴変換の補正を反映。

上記は対象HEADのソース確認に基づく変更概要で、0.9.1配布成果物での受入完了を示しません。

## サーバの導入

1. 対象OSのZIPを専用フォルダへ展開します。
2. 配布された `appsettings.json` の `ServerVersion` は `0.9.1`、待受はHTTP/2の `http://localhost:5002` です。
3. JWT秘密鍵は空です。配布先で暗号学的乱数から作成した32バイト以上の独自鍵を `WebAuthJwt__SecretKey`、または公開しない `appsettings.Production.json` へ設定してください。
4. `DOTNET_ENVIRONMENT` / `ASPNETCORE_ENVIRONMENT` を `Production` とし、展開先を作業ディレクトリにしてWindowsは `CvServer.exe`、Linuxは `chmod +x CvServer` の後に `./CvServer` を実行します。

SQLite DBは既定で作業ディレクトリの `server.db` です。新規DBでは管理者が作成され、初期ID・パスワードはどちらもDB作成日の `yyyyMMdd` です（有効期限1か月）。ログイン後に運用用の利用者設定へ変更してください。既存DBを使う場合は起動前にバックアップしてください。

別端末から接続する場合は、サーバ側のHTTPS・HTTP/2待受、証明書、ネットワーク設定を構成し、クライアントもそのURLへ合わせてください。Windowsサービス・systemdへの登録は自動では行いません。

## クライアントの導入

1. Portable ZIPを、書き込み可能な専用フォルダへ全体を展開します。
2. 展開先直下の `CreativeVision10.exe` を起動します。`current/` 以下の構成を保持してください。
3. 同梱 `current/appsettings.json` の版数は `0.9.1`、接続先は `http://localhost:5002` です。
4. 通常起動では `%LOCALAPPDATA%/CreativeVision10/clientsettings.json` の設定が優先されます。初回の設定未作成時も既存実装の初期値 `https://localhost:5012` が使われるため、ログイン前に環境設定（F10）で接続先を `http://localhost:5002`（別端末では実際のサーバURL）へ設定・保存し、再起動してください。

起動前に設定ファイルを作る場合の最小内容:

```json
{
  "ConnectionStrings": {
    "Url": "http://localhost:5002"
  }
}
```

保存済み設定がある場合は接続先だけを変更し、他の設定を上書きしないでください。

## 更新・制限

- 自動更新用のフィードは設定していません。更新時は新しい版のZIPを別フォルダへ展開し、接続先などの設定を確認して切り替えてください。
- `PrintEnable=false` で発行しており、印刷機能は利用できません。`printstream.jar`・IKVM依存は実行ファイル内部にも含めていません。
- ID・パスワード・APIキー・運用DB・証明書・秘密鍵は同梱していません。
- ARM64、Alpine/muslは対象外です。

## 確認状況

2026-10-27にWindows上で、Windows／Linux x64サーバとWindows x64 Portableクライアントのpublish・ZIP作成を実施しました。

- Windowsサーバ／クライアント本体のFileVersionと3種の同梱設定の版数が0.9.1、同梱接続先が `http://localhost:5002` で一致することを確認。3種の本体のバンドル構造を解析し、DLL・ランタイムが本体へ統合され、外部にDLL／PDBが分散していないことを確認。
- 開発設定・運用DB・証明書・秘密鍵・印刷依存の除外、空のJWT鍵、LICENSEの同梱を確認。
- ZIP内21ファイルと単一実行ファイル内部1,187項目を走査し、既知のローカル秘密値11件（UTF-8／UTF-16）、認証情報・秘密鍵の形式、設定値を照合。APIキー・パスワード・トークン等の混入は検出されませんでした。未知・暗号化済みの秘密情報すべての不在を保証する検査ではありません。
- ZIPのCRC検査、3つのSHA-256と `SHA256SUMS.txt` の独立照合を確認。

Windows／Linuxでの成果物起動、代表的gRPC操作の受入試験、コード署名は未実施です。GitHubのタグ作成・アップロード・公開と実環境への配置は人間が行います。公開前の確認は[公開手順](公開手順.md)を参照してください。
