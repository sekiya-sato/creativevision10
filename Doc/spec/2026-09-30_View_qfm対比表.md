# View と qfm の対比表

作成日: 2026-09-30
対象HEAD: `0061a566`

## 1. 目的と範囲

メインメニュー（`CvWpfclient/Models/MenuData.cs` の `CreateAll`）に登録された画面（View / ViewModel）のうち、
印刷時に `printform/*.qfm` を使うものを、メニュー階層順に一覧化する。

- 大メニュー・中メニュー・小メニューは `MenuData.cs` の登録名のまま。中メニューが無いものは `-`。
- 「店舗業務」「倉庫業務」は標準メニューへのショートカットなので、同じ View が別の行に重複して現れる。
- qfm は ViewModel（基底クラスを含む）のソースから抽出した。`_header` / `_detail` は同一 View が 2 本の qfm を順に印刷する形式。
- 1 つの View が複数の qfm を持つもののうち、`_header` / `_detail` 以外は画面上の切替（出力単位・集計単位など）で使い分ける。
- qfm を使わない画面（入力・照会・更新処理・準備中の空画面など 95 件）は載せていない。
