# 旧CVnet帳票 と CV10帳票 の対比表（大枠）

作成日: 2026-09-12
更新日: 2026-09-20
対象HEAD: `2741cc3e9633656925911143d20d0f20271919a0`

## 1. 目的と範囲

旧 CVnet の帳票集 PDF（`refer/cvnet-knowlege/帳票集PDF/`）に収録された帳票と、
CV10 に現存する帳票（`printform/*.qfm` と `CvWpfclient` の帳票画面、`MenuData.cs` のメニュー登録）
を突き合わせ、**存在／不在レベルの差分**を洗い出す。

対象業務分類は指示どおり以下の 7 冊。

| PDF | 業務分類 | 収録帳票数 |
| --- | --- | --- |
| 〔０３〕発注.pdf | 発注 | 15 |
| 〔０４〕仕入.pdf | 仕入 | 15 |
| 〔０５〕受注.pdf | 受注/展示会 | 13 |
| 〔０６〕売上.pdf | 売上 / 仕入・売上共通 | 9 / 9 |
| 〔０７〕配分.pdf | 配分 | 4 |
| 〔０８〕在庫管理.pdf | 在庫管理 | 15 |
| 〔０９〕売上分析.pdf | 売上分析 / 経営分析 / 卸分析 | 17 / 8 / 2 |
| 合計 | | **107** |

CV10 側の帳票（qfm を持つもの）は **129 件（正規化した帳票系列は117件）**。うち対象外（マスタ・予算・保守ツール）を除いた業務帳票が比較対象。

> 注: 旧 CVnet 側の件数は、帳票集 PDF の各ページ上部ヘッダ「分類 / 帳票名」を全ページ機械抽出して
> ユニーク化したもの。PDF は Adobe-Japan1 の CID フォントを使っており、CMap データ（poppler-data）を
> `xpdfrc` 経由で参照させないと本文が抽出できない点に注意（抽出手順は §5 に記載）。

- 旧 CVnet で複数形式（品番別・色サイズ別・アイテム別・ブランド別・仕入先別 等）を持つ帳票が、CV10 で単一形式になっている可能性がある。次段の詳細確認で形式単位の突合が必要。

## 5. 付録: 帳票集 PDF のテキスト抽出手順

帳票集 PDF は Adobe-Japan1 の CID フォント（`UniJIS-UCS2-H` / `90msp-RKSJ-H`）を使用しており、
CMap データが無い環境では `pdftotext` がヘッダ・帳票タイトルを一切抽出できない（本文の一部だけが出る）。

1. poppler-data（CMap 一式）を取得する。
   `https://poppler.freedesktop.org/poppler-data-0.4.12.tar.gz`
2. 展開先を指す `xpdfrc` を用意する。

   ```
   cMapDir Adobe-Japan1 <展開先>/cMap/Adobe-Japan1
   cidToUnicode Adobe-Japan1 <展開先>/cidToUnicode/Adobe-Japan1
   ```

3. `pdftotext -cfg <xpdfrc> -enc UTF-8 -layout <pdf> <txt>` で抽出する。

各ページ上部の「分類 / 帳票名」ヘッダを拾うと、そのまま帳票の目次になる。
